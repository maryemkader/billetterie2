# Billetterie – Application de gestion des événements

## 1. Présentation du projet

Billetterie est une application web développée avec Spring Boot permettant de gérer une plateforme de réservation et de billetterie pour différents événements.

L'application permet de gérer les utilisateurs, les événements, les lieux, les catégories, les types de billets, les réservations et les paiements.

## 2. Technologies utilisées

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST API
- Git et GitHub

## 3. Entités principales

- Utilisateur
- Evenement
- Lieu
- Categorie
- TypeBillet
- Reservation
- Paiement
- Tag

## 4. Base de données

Nom de la base de données : `billetterie_db`

SGBD : MySQL

## 5. Installation et exécution

1. Cloner le dépôt GitHub.
2. Ouvrir le projet dans Spring Tool Suite.
3. Créer ou vérifier la base de données MySQL `billetterie_db`.
4. Configurer les paramètres de connexion dans `application.properties`.
5. Installer les dépendances Maven.
6. Exécuter l'application Spring Boot.
